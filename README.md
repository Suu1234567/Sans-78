# Sans 78 - Color Palette Generator

A modern, interactive web application for generating random color palettes. Perfect for designers, developers, and creatives looking for inspiration!

## Features

✨ **Random Palette Generation** - Click "Generate Palette" to create a new set of 5 random colors

🎨 **Individual Color Regeneration** - Click any color box to regenerate just that color

📋 **Copy to Clipboard** - Easily copy hex color codes with one click

💾 **Export Palettes** - Download generated colors as a text file

📊 **Generation Counter** - Track how many palettes you've generated

📱 **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices

## How to Use

1. Open `index.html` in your web browser
2. Click the **"Generate Palette"** button to create a random color palette
3. Click any color box to regenerate just that color
4. Use the **"Copy"** buttons to copy hex color codes to your clipboard
5. Click **"Export Colors"** to download the palette as a text file
